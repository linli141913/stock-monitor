# 阶段6本地运行时接入包设计

## 目标

把已经完成的候选计划、研究输入提供器和单次F4编排接入现有市场影子任务，同时保持阶段6默认关闭、真实缺失明确降级、阶段5持续独立观察。

## 运行顺序

1. 市场影子任务完成本轮市场快照和同批证券行情。
2. 阶段6开关开启时，按同一 `run/asOf/quoteBatch` 构建不可变候选计划。
3. 批量研究提供器只调用一次；默认提供器不联网、不缓存、不补造，返回候选全集的显式缺失。
4. 计划未就绪、提供器阻断或全缺失时记录 `degraded` 并立即返回；不得创建 `LeaderRepository`，不得查询或写入迁移5表，也不得调用五类特征构造器或F4。
5. 只有非全缺失的已验证输入才读取历史状态、单次构建Assembly/F4，并进入既有影子仓储。
6. `formal_score_ready`、`formal_gate_ready`、`formal_usable` 和状态迁移继续固定关闭。

## 失败边界

- 阶段6异常由现有市场任务异常屏障隔离，不改变已完成的市场快照和市场任务结果。
- 缺失属于数据质量降级，不记录为健康、成功或正式可用。
- 阶段6依赖在开关分支内延迟导入；关闭时不影响既有雷达运行时加载。
- 不新增调度任务、依赖、迁移、环境变量、API或页面。

## 验收

- 开关关闭时提供器零调用。
- 默认全缺失时无需迁移5，Assembly、F4和阶段6存储均零调用。
- 提供器异常时市场任务仍完成，阶段6健康状态为失败。
- 临时迁移5数据库注入已验证输入时，只复用一批行情并写入一份 analysis-only 快照，正式可用值保持0。
- 龙头专项和完整后端回归全部通过，完整回归必须在导入旧数据库模块前重定向到临时SQLite。
