# 阶段6真实研究提供器来源上下文设计

## 目标

在接入任何真实研究来源之前，冻结同一市场任务轮次中的候选计划、候选行情、行情健康、证券主档和行业成分身份，防止提供器重新抓取或跨轮拼接。该上下文本身不提升任何来源状态。

## 来源准入审计

| 输入 | 可复用 | 当前阻断 |
| --- | --- | --- |
| 21日历史 | 腾讯前复权K线、交易日历、严格历史特征合同 | 缺当时有效行业成分生成的同口径行业等权序列和明确大盘指数合同 |
| 主营与催化 | 官方公告采集、版本化证据与人工审核合同 | 缺结构化主营事实生产适配、版本化行业催化和真实人工审核映射 |
| 可交易性 | 同轮腾讯行情、官方证券主档、2023/2026交易规则目录 | 缺官方每日全市场生命周期、停复牌、风险警示、退市整理和特殊首日参考；腾讯只能交叉校验 |
| D8/D9风险 | 巨潮元数据、受控正文、确定性事实、版本包和差异合同 | 缺全分类连续覆盖、开放事件结转、更正关系、真实人工审核和至少两个连续D8版本 |

以上四类当前均不得整体标记为 `READY`。关键词查询为空、新闻或AI摘要、简称ST、零成交、腾讯上下限、今天的行业成分倒推历史，以及复制D8制造版本，均不得用于补齐。

## 冻结上下文

- 输入必须来自已经验证为 `READY` 的候选计划及其同一 `run/asOf/quoteBatch`。
- 只保留候选行情和候选证券主档的深拷贝，以及候选行业的完整已接受证券身份集合。
- 候选、批次、时点、证券主档或行业映射任一不一致时返回稳定阻断。
- 上下文、计划和压缩证据不暴露原始行情、主档或行业记录的 `repr`。
- 上下文正式评分、门禁、可用性和状态迁移标志全部固定为 `false`。

## 不做

- 不新增来源抓取器、数据库、迁移、调度、依赖、环境变量、API或页面。
- 不启用阶段6，不重载服务，不写生产SQLite。
- 不把公开辅助源升级为官方主源。

## 后续门槛

第一优先仍是C4官方每日可交易性参考。必须先获得交易所参与者文件/行情网关，或选择能够提供同等字段、时点、覆盖和授权证明的合规数据服务；未确认来源前不编写假定字段的生产解析器。
