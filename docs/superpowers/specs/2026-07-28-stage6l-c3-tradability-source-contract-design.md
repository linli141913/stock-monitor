# 阶段 6L-C3 可交易性来源合同设计

## 目标

在阶段 6L-C1 的只读研究证据合同和 6L-C2 的真实来源 POC 之上，完成本地
可测试的来源组装层：

1. 版本化保存沪深 2023/2026 交易规则；
2. 解析腾讯同一行情响应中的字段 47、48，作为可选辅助校验；
3. 定义官方逐证券参考输入的严格合同；
4. 对官方参考、规则目录、生命周期证据和腾讯辅助值做冲突检测；
5. 只在证据完整且一致时生成 C1 输入，继续保持正式门禁关闭。

## 变更分类

- **保留**：C1 的生命周期、交易状态、交易规则和研究结果合同。
- **增强**：`QuoteSnapshot` 增加可选上下限源字段；腾讯源不增加请求次数。
- **新增**：版本化规则目录、官方参考输入合同、来源组装结果和纯解析函数。
- **暂缓**：真实官方文件接入、数据库、调度、API、前端和生产配置。
- **不替换**：不替换现有行情源，也不改变正式龙头评分与状态机。

## 数据合同

### 腾讯辅助字段

`QuoteSnapshot` 增加两个非必填字段：

- `upperLimitPriceSource`：腾讯响应字段 47；
- `lowerLimitPriceSource`：腾讯响应字段 48。

两者只接受有限、非负数；空值和非法值均保存为 `null`。它们不进入
`REQUIRED_FIELDS`，不改变现有字段覆盖率，也不触发额外行情请求。

### 版本化规则

规则目录按交易所、板块和交易日选择有效版本。C3 只覆盖：

- 上交所、深交所 2023 年修订规则，至 2026-07-05；
- 上交所、深交所 2026 年修订规则，自 2026-07-06；
- 沪深主板普通股、风险警示股；
- 科创板、创业板；
- 上市前 5 个交易日、重新上市首日和退市整理期首日的无涨跌幅限制。

2026-07-05 以前的主板 ST、*ST 为 5%，自 2026-07-06 起为 10%。
科创板、创业板在本目录覆盖区间内为 20%。更早历史不在 C3 假定完整。

每条规则保存：

- 交易所和板块；
- 规则版本；
- 发布日期；
- 生效和失效日期；
- 普通与风险警示证券的比例；
- 官方来源名称、文档编号和 HTTPS 原文地址。

### 官方逐证券参考

官方参考输入必须显式提供：

- 证券代码、交易所、板块和交易日；
- 生命周期状态、交易状态和特殊交易日类型；
- 涨跌幅模式、当日上限和下限；
- 来源合同编号、来源名称、源时间和抓取时间；
- 来源准入等级。

输入只接受 C2 冻结的来源等级。只有 `official_primary` 可以生成 C1 输入；
`official_restricted_candidate` 表示仅有接口规范而无真实文件，不能生成数据。
无真实参考文件时返回 `missing` 和
`official_reference_source_unavailable`，不得用腾讯或名称推断补齐。

## 规则解析

解析器是无网络、无数据库的纯函数：

1. 按交易日选择唯一规则版本；
2. 按板块与生命周期选择适用比例；
3. 上市前 5 个交易日、重新上市首日、退市整理期首日解析为 `no_limit`；
4. 有涨跌幅限制时，按前收盘价和最小价格单位 0.01 元计算预期上下限；
5. 结果只用于校验官方参考，不单独生成正式交易规则证据。

价格计算使用十进制四舍五入到 0.01 元，比较容差沿用 C1 的 0.005 元。

## 来源组装与冲突

组装器接收 C1 生命周期证据、同证券行情快照和可选官方参考：

1. 校验证券代码、交易所、板块、交易日和有效时间；
2. 校验官方生命周期与调用方版本化生命周期一致；
3. 校验官方涨跌幅模式、绝对上下限与规则目录一致；
4. 腾讯辅助值存在时，与官方绝对上下限交叉校验；
5. 证据完整且无冲突时，生成 `LeaderTradabilityFeatureInput`；
6. 任一冲突返回 `source_unverified`，不选择其中一方继续计算；
7. 官方参考缺失返回 `missing`，交易状态保持未知。

来源优先级为官方逐证券参考、官方规则目录、腾讯辅助校验。腾讯字段缺失不降低
已完整官方证据；腾讯字段与官方冲突则整项降级。

## 输出边界

来源组装结果必须显式包含：

- 状态；
- 可选的 C1 输入；
- 规则版本、适用模式和比例；
- 去重后的原因；
- 来源引用；
- 固定 `scoreReady=false`、`formalUsable=false`。

即使来源组装和 C1 研究计算均为 `ready`，也不得打开
`tradability_passed`、正式候选、交易建议或状态机迁移。

## 明确不做

- 不读取或写入生产 SQLite。
- 不新增迁移、仓储、调度、API、前端、依赖或环境变量。
- 不接入需要权限的交易所真实参考文件。
- 不从简称、成交量、价格为零或无行情推断状态。
- 不把腾讯辅助值称为官方证据。
- 不重启或重载 4000/8001。
- 不执行 Git 暂存、提交或推送。

## 验收

- 2023/2026 切换和主板 ST 比例有边界测试。
- 主板、科创板和创业板规则有测试。
- 三类无涨跌幅限制交易日有测试。
- 腾讯字段 47、48 的正常、空值和非法值有测试，且请求次数不变。
- 官方参考缺失返回 `source_unavailable` 原因。
- 官方、生命周期、规则目录和腾讯冲突均会降级。
- 可信证据可生成 C1 输入，但研究结果和运行时正式门禁仍为关闭。
