# 阶段6候选全集官方主营材料与人工复核设计

## 目标

为同一份阶段6候选计划发现可追溯的巨潮官方披露材料，形成逐候选、不可自动判定主营关联的人工复核清单；只有人工提交与清单、候选计划及官方文档完全一致的结构化事实后，才转换为现有主营催化官方工件并进入既有人工复核与生产 collector。

## 边界

- 只处理沪深阶段6候选计划，不扩大股票池。
- 只接受 cninfo.com.cn / static.cninfo.com.cn 官方元数据和文档链接。
- 发现层只保存文档身份、标题、发布时间、来源和覆盖状态，不解析或猜测主营事实。
- 人工提取层要求明确的事实摘要、证明类型、文档版本和催化材料；AI、证券简称、新闻标题及主题标签不能生成正式关系。
- 全集任一候选缺材料、查询失败、覆盖不完整或未人工复核时，整批不能进入现有 READY 主营输入。
- 所有结果默认关闭正式评分、正式门、正式可用和状态迁移。
- 本批不连接生产 SQLite、不新增依赖、不修改环境变量、不重启服务、不调用付费 AI。

## 组件

1. radar/sources/leader_business_official.py：巨潮主营材料查询、严格解析和分页覆盖合同。
2. radar/leader_business_material_review_queue.py：候选计划顺序的人工复核清单。
3. radar/leader_business_material_human_extraction.py：严格校验人工提取后生成现有官方材料工件。

- 运行主营链相关测试、阶段6联合测试、隔离生产 SQLite 的完整后端测试、Python 编译和 git diff --check。
