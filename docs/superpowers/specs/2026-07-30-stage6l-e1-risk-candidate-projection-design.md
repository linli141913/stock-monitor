# 阶段 6L-E1 风险研究证据到候选输入的只读投影设计

## 目标

把 D9 已审计的当前 D8 风险研究证据包、相邻版本差异和正式门禁缺口，
转换为候选龙头能够保存和展示的只读研究证据。研究投影就绪不代表风险
过滤通过，也不生成、关闭或替代任何正式风险事件。

## 输入与重算边界

`LeaderRiskCandidateProjectionInput` 包含：

- 候选证券代码；
- 候选发行人身份；
- 带时区的候选批次 `as_of`；
- 原始 `RiskResearchEvidenceBundleAuditInput`；
- 调用方持有的 `RiskResearchEvidenceBundleAuditResult`。

入口必须重新执行 D9，并与调用方结果逐字段相等。D9 未就绪、历史不足、
输入冲突或调用方结果被伪造时，不生成部分投影。

## 身份与时间合同

当前 D8 证据包的证券代码和发行人身份必须与候选完全一致。`built_at`、
`content_fetched_at` 和 `target_event_published_at` 都不得晚于候选批次
`as_of`。输入缺少时区、身份不一致或包含未来证据时整体拒绝。

## 输出合同

冻结投影只保存：

- E1、D9 和 D8 合同版本；
- 候选证券、发行人和批次时间；
- 有序 D8 包 ID、当前包 ID及当前包构建时间；
- 来源文档、内容快照、事实、人工工件和研究关系的压缩身份；
- D9 的相邻版本结构化差异；
- 当前正式门禁缺口。

`to_evidence()` 输出 JSON 兼容的候选研究证据，保留真实枚举值、ISO 时间、
事实 ID 的原始顺序以及 D9 相邻差异，不保存 URL、标题、正文、事件摘要、
人工审核摘要、原始人工值或 PDF 片段。

## 正式门禁

E1 v1 固定：

- `risk_filter_passed=false`；
- `formal_gate_ready=false`；
- `formal_usable=false`；
- `applied_to_d3=false`；
- `applied_to_d1=false`。

输出可以是研究状态 `ready`，但必须保留全部 D8 正式门禁缺口。E1 不提供
把上述标志改为 `true` 的输入参数。

## 字段级数据合同

- 主源：D9 重新审计后选择的当前 D8 冻结证据包；
- 备用源：无；
- 数据时间：D8 `built_at`、`content_fetched_at` 和目标事件发布时间；
- 最大延迟：本阶段不推断业务有效期，只拒绝未来数据；
- 覆盖率：不伪造百分比，以 D8 正式门禁缺口完整列举；
- 缺失语义：D9 历史不足为 `missing`；
- 冲突策略：合同、身份、顺序、时间或重算冲突时整体不可验证；
- 本轮参与：只进入候选研究证据，不参与正式评分、风险过滤或状态机。

## 明确不做

- 不修改 `LeaderInputEvidence`、运行时组装器或评分门禁；
- 不生成 `LeaderRiskResolutionEvidence`；
- 不写回 D1、D3、D8 或 D9；
- 不连接 SQLite、仓储、调度、API、前端、提醒或 AI；
- 不新增迁移、依赖、环境变量或运行开关；
- 不运行真实人工审核。

## 验收

1. 合法 D9 链投影当前 D8 包、全部包 ID、相邻差异和门禁缺口；
2. 伪造 D9 结果、身份冲突、未来证据和畸形输入稳定拒绝；
3. D9 缺失或失败状态原样传播，不输出部分投影；
4. 正式标志固定关闭，输出不可变且不泄露敏感文本；
5. E1 专项、D1-E1 联合、龙头全量和后端完整回归通过。
