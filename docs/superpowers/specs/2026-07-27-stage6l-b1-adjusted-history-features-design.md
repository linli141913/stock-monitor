# 阶段 6L-B1 同口径复权历史研究特征设计

## 1. 目标

阶段 6L-B1 在阶段 6L-A 当期横截面研究特征之后，新增可验证的历史
连续性研究证据。它只计算原始历史指标，不冻结 20 分正式评分公式，不改变
龙头门禁、状态机、只读 API 或生产开关。

阶段 5 的 20 个交易日影子观察与本阶段并行，不能由本地测试替代。

## 2. 方案选择

采用“纯合同和原始证据”方案：

- 调用方显式提供候选股票、点时行业基准和板块指数的连续价格序列；
- 纯函数校验复权、收益、日期、来源和时间合同；
- 计算 3、5、10、20 日价格收益、相对收益、连续跑赢天数、最大回撤和
  谷底修复；
- 结果写入候选 `evidence.researchFeatures.historyContinuity`；
- 正式 `relative_strength_continuity` 维度继续不带分数，状态机继续
  `blocked/out`。

不采用盘中逐股抓取。当前没有经过容量、限频和公司行为验证的全市场同复权
历史适配器，盘中对数百只候选逐股请求会引入来源断连、时间不一致和未来数据
污染。

## 3. 数据合同

新增三个序列角色：

- `candidate_security`：候选股票，必须为 `forward_adjusted`；
- `industry_benchmark`：行业基准，必须为
  `point_in_time_equal_weight_price_return`，表示按当时行业成员计算；
- `board_index`：板块指数，必须为 `continuous_index`。

三个序列的收益口径都必须为 `price_return`。现金分红总回报不能与价格收益
混算。

每个序列保存：

- 角色、标识和来源合同标识；
- 复权或连续口径、收益口径；
- 来源状态、来源时间和抓取时间；
- 按交易日升序排列的正数收盘值。

调用方还必须提供预期交易日序列。最近 21 个交易日必须与三个价格序列逐日
一致，才能计算 20 个交易日收益；不得只检查自然日首尾。

## 4. 时间和质量门禁

以下任一条件不满足时不计算研究指标：

- 少于 21 个连续交易日；
- 日期重复、倒序、断档或三个序列日期不一致；
- 收盘价缺失、非有限、为 0 或负数；
- 角色、复权口径或收益口径不符合合同；
- 来源时间或抓取时间没有时区、来自未来或抓取早于来源时间；
- 任一来源为缺失、未验证、过期或失败。

失败结果保留稳定状态和原因，不用 0 替代缺失，不返回完整价格序列。

## 5. 原始研究指标

可用结果计算：

- 三个序列各自的 3、5、10、20 日价格收益；
- 候选相对行业和相对板块指数的同期超额收益；
- 最近 5 日和 10 日候选日收益高于行业、板块指数的交易日数量；
- 最近 20 日三个序列的最大回撤；
- 候选最大回撤相对行业和板块指数的抗跌差值；
- 最近 20 日发生实际回撤时，从最大回撤谷底到最后交易日的修复收益。

真实 0 收益、0 个跑赢日和 0 修复收益必须保留。若窗口内没有发生实际回撤，
修复收益保持缺失并记录 `recovery_event_absent`，不能伪造为 0。

## 6. 运行时接入

`build_leader_runtime_evidence` 新增可选的按股票代码索引的历史输入。默认
未提供时保持现有 `continuity_history_missing` 行为。

提供并通过合同后：

- `historyContinuity.status=ready`；
- `historyContinuity.scoreReady=false`；
- 正式维度仍为无分数的 `source_unverified`；
- 原因改为 `continuity_research_only`；
- `continuity_passed` 仍为 `false`；
- 正式缺失前置项改为 `continuity_formal_rule`。

这表示“原始历史证据已经可算”，不表示“20 分正式规则已经冻结”。

## 7. 明确不做

- 不访问外部历史行情；
- 不读取或写入生产数据库；
- 不新增迁移、缓存表、文件缓存或依赖；
- 不修改调度、环境变量、LaunchAgent、API、页面、提醒或 AI；
- 不把研究指标转换为正式分数；
- 不启用阶段 6 生产开关；
- 不提交或推送 Git。

## 8. 测试与回退

纯函数测试覆盖正常指标、真实 0、日期断档、日期错位、复权口径冲突、未来
时间、来源失败、非法价格、实际回撤修复和无回撤事件。

运行时测试覆盖默认兼容行为、可用历史证据接入、正式分数继续缺失、状态机
继续阻断，以及不发生网络请求或数据库访问。

回退只需撤回独立历史特征模块、运行时可选参数、对应测试和本文档；阶段
6L-A、阶段 5 影子观察及当前生产服务不受影响。
