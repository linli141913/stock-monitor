# 阶段 6L-C2 可交易性真实来源只读 POC Plan

**Goal:** 核对阶段 6L-C1 所需的证券生命周期、当日交易状态和版本化涨跌幅
规则真实来源，形成来源准入结论和下一阶段最小边界。

**Deliverable:** 只读 POC 记录、来源等级、冲突策略和 C3 建议；不修改生产
运行时。

## Global Constraints

- 不读取或写入生产 SQLite。
- 不修改生产环境变量、系统启动项或运行配置。
- 不停止、重启或重载 4000/8001。
- 不新增依赖、数据库迁移、仓储、API、前端或调度。
- 不从简称、零成交、价格 0 或无行情推断证券状态。
- 不执行 Git 暂存、提交或推送。
- 阶段 5 的 20 个交易日观察继续并行。
